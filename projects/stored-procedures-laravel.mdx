Desarrollé una pequeña herramienta para facilitar la integración de **Stored Procedures** en proyectos con **Laravel 10**. La solución permite encapsular todos los procedimientos almacenados dentro de una carpeta específica del proyecto, y al ejecutar `migrate`, se aplican automáticamente a la base de datos.

El funcionamiento es simple: solo se deben agregar o quitar archivos `.sql` con los procedimientos deseados dentro de esa carpeta, sin necesidad de gestionarlos manualmente. Esto permite mantener una estructura organizada, reproducible y fácilmente versionable del esquema de procedimientos almacenados.
