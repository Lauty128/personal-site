> La idea del proyecto nacio en 2023 pero en Julio del 2025 salio la version beta a producciòn

AutoDealer es una solución web pensada para digitalizar y simplificar la gestión de concesionarios de vehículos usados. Surge como respuesta a una necesidad concreta: muchos concesionarios siguen utilizando planillas o procesos manuales para organizar su stock, ventas y gastos, lo que genera desorden, pérdida de información y falta de visibilidad sobre el negocio.

AutoDealer centraliza toda la operación en una sola plataforma accesible desde cualquier dispositivo, ayudando a mejorar la eficiencia, el control y la presencia online del concesionario.

### ¿Qué necesidades resuelve?

* Permite mantener un registro organizado del stock de vehículos, sus características, precios y estado.

* Mejora el seguimiento de ventas y gastos, brindando reportes claros que ayudan a tomar mejores decisiones.

* Facilita la presencia online, ya que cada concesionario cuenta con una página web propia donde puede publicar sus vehículos.

* Aporta herramientas para gestionar vendedores, su rendimiento y las ventas asignadas.

* Elimina la dependencia de herramientas externas como Excel o redes sociales mal gestionadas.

### Módulos principales

* Gestión de vehículos: Carga, edición, filtrado y publicación del stock.

* Ventas y gastos: Registro detallado de operaciones, ingresos, egresos y balances.

* Sitio web personalizado: Cada concesionario cuenta con su propia página, adaptada con sus colores e identidad visual.

* Módulo de vendedores: Permite asignar ventas a distintos vendedores, hacer seguimiento y organizar mejor al equipo comercial.

### Infraestructura y arquitectura

AutoDealer está desarrollado sobre una arquitectura moderna basada en una API centralizada, que actúa como punto de conexión entre los distintos componentes del sistema.
El sitio web público, donde los visitantes pueden explorar los vehículos disponibles, está construido con Laravel, brindando rapidez y facilidad de navegación. Por otro lado, el sistema de gestión interna utilizado por los concesionarios fue desarrollado con React, conectándose a la API mediante tokens de acceso Bearer, lo que garantiza un intercambio de datos seguro y controlado.

Esta separación entre frontend y backend permite una mejor escalabilidad, mantenimiento y seguridad, asegurando que cada usuario acceda únicamente a su información correspondiente.
