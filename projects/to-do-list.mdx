El proyecto consiste en el desarrollo de una aplicación de lista de tareas (To-Do List) implementada utilizando las tecnologías web estándar: HTML, CSS y JavaScript. La singularidad de esta aplicación reside en su capacidad para aprovechar el almacenamiento en caché del navegador, eliminando la necesidad de una conexión a una API o base de datos externa para persistir la información.

### Características Destacadas:

1. **Almacenamiento en Caché:**
   - El To-Do List utiliza el almacenamiento en caché del navegador para retener la información, permitiendo a los usuarios acceder a sus tareas incluso después de cerrar la ventana del navegador.

2. **Operaciones Básicas:**
   - **Agregar Nueva Nota:**
     - Los usuarios pueden agregar nuevas notas, cada una con un título de entre 5 y 30 caracteres y una descripción de entre 30 y 140 caracteres.
     - Se implementan expresiones regulares para validar la longitud de los campos del título y la descripción.

   - **Modificar Nota:**
     - La aplicación permite la modificación de notas existentes.
     - Se realiza una validación para detectar si no se realizaron cambios en la nota durante la edición, y en tal caso, se muestra un mensaje de error indicando que los valores son idénticos.

   - **Eliminar Nota:**
     - Los usuarios pueden eliminar notas, proporcionando una interfaz fácil y rápida para gestionar sus tareas.

3. **Ordenamiento por Carga:**
   - El orden de las notas en la lista se basa en el momento de carga de cada nota. La primera nota cargada se coloca al final de la lista, y las notas más recientes se sitúan en la parte superior.


### Notas Adicionales:

- La implementación se centra en una experiencia de usuario fluida y eficiente, aprovechando las capacidades del navegador para almacenar datos de manera local.

- La validación con expresiones regulares garantiza que los datos ingresados cumplan con los requisitos especificados, proporcionando una interfaz robusta y fácil de usar.
