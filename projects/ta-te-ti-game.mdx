Este proyecto fue desarrollado cuando me encontraba aprendiendo acerca del DOM de JavaScript.

El juego cuenta con un algoritmo que detecta cuando hay un ganador y no permite realizar mas movimientos hasta que se reinicie el juego.

Este juego tiene un estilo minimalista y cuenta con animaciones para indicar al usuario el estado actual del juego.

### Características

* Se utilizo POO para administrar las acciones de los usuarios sobre el juego y para renderizar los distintos objetos que se pueden visualizar en el mismo.

* Los iconos de juego son elementos HTML con unos estilos CSS

* Adaptado para celulares
